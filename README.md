# 🎯 Juego: Adivina el Número Mágico

Este proyecto es el **Ejercicio 1 del Trabajo Práctico de DOM y BOM** 


---

## 🧠 Descripción

Este juego permite al usuario adivinar un número aleatorio entre 1 y 100. Al iniciar el juego se genera un número mágico, y el usuario debe ingresar intentos hasta adivinarlo. Se le brindan pistas indicando si el número ingresado es mayor o menor que el número mágico.

---

## 💻 Tecnologías utilizadas

- HTML5
- CSS3 (Bootstrap 5 para estilos responsivos)
- JavaScript (DOM y BOM)

---

## 🚀 Cómo usarlo

1. Abrí `index.html` en un navegador.
2. Hacé clic en **“Comenzar el Juego”**.
3. Ingresá un número y presioná **“Enviar”**.
4. Recibirás pistas hasta adivinar el número mágico.
